# 资料命名规范

## 目录结构

每门课使用固定的资料类型目录：

```text
课程名/
  复习讲义/
  往年真题/
  课件PPT/
  课件资料/
  课件资料包/
```

没有对应资料时不要新建空目录。不要为了凑目录上传生成内容。

## 文件命名格式

统一使用：

```text
课程名_资料类型_关键信息[_年份或版本].扩展名
```

示例：

```text
离散数学_真题_软件学院23级.pdf
大学物理_课件_2023高斯定理.pdf
面向对象程序设计Java_课件_第1章Java概述.pptx
Web编程基础_考前复习知识点讲义.pdf
```

## 资料类型词

- `真题`：往年真题、回忆版真题。
- `样卷`：模拟卷、样题、练习卷。
- `课件`：真实课程 PPT/PPTX/PDF 课件。
- `讲义`：复习讲义、知识点讲义。
- `题库`：习题集、题库、练习题。
- `答案解析`：答案、解析、题解。
- `资料包`：无法拆分但来源明确的 ZIP 压缩包。

## 字符规则

- 使用中文课程名，不使用拼音缩写。
- 多编号使用顿号：`D7-1、2、3`。
- 版本说明使用下划线：`_精简版`、`_删减版`、`_02`。
- 避免使用英文逗号、斜杠、冒号、问号、星号。
- 文件名不要出现 `副本`、`final_final`、`新建文件`、`未命名`。

## 真实性要求

- `课件PPT` 目录只放真实 PPT/PPTX 课件。
- 如果只有 PDF 课件，放入 `课件资料`。
- 如果只有压缩包，放入 `课件资料包`。
- 禁止上传 AI 生成 PPT 冒充课程课件。
