# 资料命名规范

## 目录结构

每门课使用固定的 canonical 资料类型目录。没有对应资料时不要新建空目录，不要为了凑目录上传生成内容。

```text
课程名/
  复习讲义/
  往年真题/
  课件/
  题库练习/
  答案解析/
  笔记总结/
  电子版教材/
  待复核资料/
```

## Canonical 资料类型

- `复习讲义`：考前复习讲义、知识点讲义、课程知识框架。
- `往年真题`：往年真题、回忆版真题、确认属于考试卷的历史试卷。
- `课件`：真实课程课件，不按文件格式拆分类别；PPT、PPTX、PDF、DOCX 或合理保留的 ZIP 都可以属于课件。
- `题库练习`：习题集、题库、练习题、模拟练习。
- `答案解析`：答案、解析、题解。
- `笔记总结`：同学公开整理的笔记、总结、索引。
- `电子版教材`：允许公开再分发的电子教材、开放教材或经授权教材。
- `待复核资料`：来源、年份、课程归属、公开边界或真实资料类型尚需确认的内容。

不要创建 `完整复习包`、`付费资料`、`会员资料` 等公开仓库不应出现的目录。

### 历史目录兼容

仓库现有以下旧目录时可暂时保留，等待单独迁移：

- `课件PPT` → `课件`
- `课件资料` → `课件`
- `课件资料包` → `课件`
- `待复核课件PPT` → `待复核资料`

新资料不得继续创建或写入这些 legacy 目录。资料类型描述内容语义，扩展名描述文件格式，两者不要混在一起。

## 文件命名格式

统一使用：

```text
课程名_资料类型_关键信息[_年份或版本].扩展名
```

示例：

```text
离散数学_真题_软件学院23级.pdf
大学物理_课件_2023高斯定理.pdf
面向对象程序设计Java_课件_第1章Java概述.pptx
Web编程基础_考前复习知识点讲义.pdf
高等数学A（二）_课件_D10-3三重积分_02.ppt
数据库系统_教材_数据库系统概论.pdf
```

## 文件名中的资料类型词

- `真题`：往年真题、回忆版真题。
- `样卷`：模拟卷、样题、练习卷。
- `课件`：真实课程课件，不区分 PPT/PDF/DOCX。
- `讲义`：复习讲义、知识点讲义。
- `题库`：习题集、题库、练习题。
- `答案解析`：答案、解析、题解。
- `笔记`：同学公开整理的笔记、总结、知识点索引。
- `教材`：电子版教材。
- `待复核`：仅用于尚未完成归类的资料。

文件名中的描述词可以比目录 role 更具体，但不能造成类型误导。

## 字符规则

- 使用中文课程名，不使用拼音缩写替代课程名。
- 多编号使用顿号：`D7-1、2、3`。
- 高数章节编号统一使用 `D` 前缀：`D7-5`、`D8-1`、`D10-3`，不要混用 `7-5` 或 `8-1`。
- 版本说明使用下划线：`_精简版`、`_删减版`、`_02`。
- 避免使用英文逗号、斜杠、冒号、问号、星号、引号、尖括号和反斜杠。
- 文件名不要出现 `副本`、`final_final`、`新建文件`、`未命名`。

## 真实性与公开边界

- `课件` 只放真实课程课件，不得用 AI 生成 PPT 冒充真实课件。
- 课件 ZIP 能安全拆分时，优先保留有价值的单文件；只有确有必要时才保留压缩包。
- 电子版教材必须确认允许公开再分发；不得上传盗版或明显未经授权的商业教材。
- 来源不确定、课程归属不确定、年份不确定且影响判断、或公开边界不确定的资料，统一先放入 `待复核资料` 并在 PR 中说明。
- 确认错科后应移动到正确课程，不要长期留在 `待复核资料`。

## Manifest 同步

所有新增、删除、移动、重命名资料，都必须同步更新 `manifest.json`。具体字段和兼容规则以 [manifest.md](manifest.md) 为准。

至少保留：

- `subject`
- `role`
- `title`
- `publicPath`
- `bytes`
- `sha256`

建议逐步补充：

- `year`
- `college`
- `major`
- `sourceType`
- `sourceNote`
- `reviewStatus`
- `uncertainty`
- `containsPersonalInfo`
- `licenseStatus`
- `attribution`

提交前运行：

```bash
node scripts/refresh-manifest-metadata.mjs --check
node scripts/validate-materials.mjs
node scripts/update-readme.mjs --check
```
